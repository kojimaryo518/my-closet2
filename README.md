# MY CLOSET

9着の洋服図鑑。カテゴリーとブランド・商品名・色・品番で検索し、カードを押すと詳細を表示します。

固定公開URL: https://kojimaryo518.github.io/my-closet2/

## 公開

GitHub PagesのSourceをGitHub Actionsに設定し、承認済みの変更をmainへ反映すると、pages.ymlが公開用ファイルだけをデプロイします。リポジトリ名と所有者を変更しない限りURLは同じです。

## データ

index.html内のitemsが画面用データ、items.jsonが同じ登録情報の一覧です。更新時は両方を同期してください。画像はassets/に保存し、外部サイトには依存しません。

登録情報は既存のmy_closet_interactive_9.htmlから引き継ぎました。画像は元写真を参考に生成された商品イメージで、実物写真ではありません。正式商品名が未特定の項目は仮称です。価格や発売時期は未確認のため掲載していません。

## 操作

カテゴリーを選択して絞り込み、検索語を入力します。カードで詳細を開き、閉じるボタン・背景タップ・Escapeで閉じます。キーボード操作とモーダル内のフォーカス移動に対応しています。
